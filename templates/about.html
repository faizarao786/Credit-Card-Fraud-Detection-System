Credit Card Fraud Detection System

This system is designed to analyze credit card transaction data and identify transactions that may be potentially fraudulent. It uses machine learning to study transaction patterns and classify individual transactions as either normal or fraudulent.

Project Overview

Credit card fraud is a major challenge for financial institutions because fraudulent transactions can result in financial losses and security risks. This project provides a simple machine-learning-based solution for analyzing transaction data and detecting suspicious activity.


The application provides a web interface where users can view transaction statistics, analyze the dataset, inspect transaction records and perform fraud detection on individual transactions.

Project Objective

The main objective is to demonstrate how machine learning can be integrated into a practical web application for financial fraud detection.


The system combines data processing, machine learning, prediction and a Flask-based web interface into one complete application.

Machine Learning Model

The current system uses Logistic Regression with balanced class weights. This is useful for the project because credit card fraud datasets are highly imbalanced, meaning fraudulent transactions are much fewer than normal transactions.

Algorithm Logistic Regression
