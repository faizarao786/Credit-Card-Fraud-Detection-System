🚀 Getting Started

FraudGuard is a Credit Card Fraud Detection System that uses a machine learning model to identify potentially fraudulent transactions.

  • Login to your FraudGuard account.
  • Open the Dashboard.
  • Use Detect Fraud for an individual transaction.
  • Use Bulk Prediction for multiple transactions.
  • Check Analytics for transaction statistics.
  • Check Prediction History for previous predictions.

🔍 How to Detect Fraud

The Detect Fraud page allows you to check an individual credit card transaction using the trained machine learning model.

  • Enter the transaction Time.
  • Enter the V1 to V28 transaction values.
  • Enter the transaction Amount.
  • Click the prediction button.
  • The system will process the transaction.
  • The prediction result will then be displayed.

The result can indicate whether the transaction is Normal or Fraudulent.

📂 Bulk Prediction

Bulk Prediction allows you to upload a CSV file containing multiple credit card transactions.

  • Prepare a CSV file with the required columns.
  • Upload the CSV file.
  • Start the prediction process.
  • Review the prediction results.

The required transaction columns include Time, V1 to V28, and Amount.

📊 Analytics

The Analytics page provides visual information about the dataset and prediction results.

  • Total transactions
  • Normal transactions
  • Fraudulent transactions
  • Fraud rate
  • Transaction amount information
  • Charts and graphs

📜 Prediction History

Prediction History stores predictions made through the individual fraud detection system.

  • View previous predictions.
  • See prediction date and time.
  • See transaction amount.
  • See Normal or Fraud result.
  • View fraud probability when available.

⚙️ Settings

The Settings page allows you to manage available application preferences.

  • Dark/Light appearance options
  • Notification preferences
  • Prediction result format
  • Currency preference
  • Account information

❓ Frequently Asked Questions

Q: What is FraudGuard? A: FraudGuard is a machine learning based credit card fraud detection system.
Q: What does "Normal" mean? A: It means the machine learning model classified the transaction as a normal transaction.
Q: What does "Fraud" mean? A: It means the model classified the transaction as potentially fraudulent.
Q: Can I check multiple transactions? A: Yes. Use the Bulk Prediction page to upload a CSV file containing multiple transactions.
Q: Where can I see previous predictions? A: Open the Prediction History page from the dashboard.
Q: What should I do if the system shows an error? A: Check that all required fields are filled correctly and that the uploaded CSV contains the required columns.
